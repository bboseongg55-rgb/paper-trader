# 자동매매 연습장 (paper-trader)

가상 자금 10만 달러로 미국 대형주를 자동으로 매매하는 연습 계좌입니다. 실제 돈과 증권 계좌는 쓰지 않으며, 투자 권유가 아닙니다.

- **화면**: https://bboseongg55-rgb.github.io/paper-trader/ (계좌 · 체결내역 · 수익 세 탭, 휴대폰 홈 화면에 추가하면 앱처럼 열립니다)
- **수수료**: 로빈후드 기준. 위탁 수수료 없음, 매도 때 SEC 수수료(100만 달러당 $20.60, $500 이하 면제)·FINRA 수수료(주당 $0.000195, 최대 $9.79, 50주 이하 면제, 2026년 10~12월 일시 중단), 매수·매도 때 CAT 수수료(주당 $0.000003, 1센트 미만 면제)
- **움직이는 방식**: GitHub Actions 작업 하나가 미국 장중 내내 켜져 약 5분마다 공개 시세(API 키 없음)를 받아 `engine.js`를 돌리고 결과(`data/state.json`)를 저장합니다. 화면은 그 파일을 2분마다 다시 읽습니다.
  - 손절·추적 손절은 장중에 바로 확인합니다.
  - 손실이 나면 그 자리에서 원인을 복기하고, 같은 원인이 반복되면 규칙을 스스로 고칩니다(범위 안에서만).
  - 새 매수는 장 마감 직전(15:50 무렵, 뉴욕 시간) 가격으로 판단합니다.
  - 매일 저녁 공개 저장본의 공식 종가와 S&P 500 값으로 빠진 날을 채웁니다.
- **AI팀 네 개**: 종목선정팀(상승 추세·상대강도 상위 후보), 매수팀(매수 신호·수량, 방법별 위험 배분), 매도팀(손절·추적 손절·기한·목표가, 단타 당일 정리), 리스크·헷지팀(시장 필터, 손실 브레이크, S&P 500 인버스 헷지). 각 팀이 자기 규칙을 결과에 맞춰 스스로 고칩니다.
- **헷지**: 다음 날로 넘기는 주식이 있고 S&P 500이 평균선 아래면, 보유 주식의 일정 비율만큼 S&P 500 인버스(SH와 같은 −1배, 연 0.89% 비용)를 듭니다.
- **체결 잠금(장부)**: 장 마감으로 종가가 확정된 날은 `data/book.json`에 계좌 상태와 함께 저장되고, 다음 실행은 거기서 이어갑니다. 엔진이나 규칙이 바뀌어도 확정된 체결은 다시 계산되지 않습니다.
- **진화 연구소**(`evolve.js`, `data/evolution.json`): 매일 장 마감 뒤 지금 규칙을 조금씩 바꾼 후보 16개를 지난 1년의 앞뒤 두 기간에서 시험하고, 두 기간 모두 나은 후보는 그림자 계좌에서 함께 매매합니다. 20거래일 넘게 지켜본 뒤 지금 규칙보다 1%p 이상 더 벌고 낙폭이 1%p 넘게 크지 않으면 다음 거래일부터 새 세대 규칙이 됩니다. 바꾸기 전 규칙도 그림자로 남아, 더 나으면 되돌아갑니다. 위험 한도(1회 위험, 열린 위험, 손실 정지)는 진화 대상이 아니고, 시장 필터·종목당 비중·헷지는 처음보다 느슨해지지 않습니다.
- **파일**
  - `engine.js`: 매매·리스크 관리·자기 교정 엔진
  - `tools/collect.mjs`: 장중 가격 수집, `tools/run.mjs`: 엔진 실행, `tools/feed_live.py`·`tools/merge_feed.mjs`: 저녁 종가 보충
  - `data/`: 가격 기록(`seed.json` 과거, `live.json` 연습 기간, `intraday/` 보유 종목 장중 가격)
  - `.github/workflows/trade.yml`: 실행 일정

수동 실행: Actions → trade → Run workflow (`session` 장중 수집 시작, `rebuild` 다시 계산, `probe` 가격 출처 점검).
